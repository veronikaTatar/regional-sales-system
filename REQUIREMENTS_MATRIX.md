## Фактические результаты

Базовые сценарии проверены 16.11.2026.

- Backend: `mvn test package` с `MYSQL_INTEGRATION_TESTS=true` — **22 теста, 0 ошибок, 0 пропусков**, исполняемый JAR собран. 18 проверок безопасности/доступа и 4 интеграционные проверки MySQL.
- Frontend: `npm test` — **9 тестов**, `npm run build` — успешно. Шрифты включены локально без внешних CDN.
- MySQL **8.4**: Flyway V1–V3 применены; Hibernate `validate` пройден; проверены generated суммы, внешние ключи, запрет удаления истории, уникальность статистики и позиций, CHECK числовых значений и данных утверждения. Изменения интеграционных тестов откатываются транзакциями.
- Реальный HTTP smoke: регистрация менеджера, профиль, отсутствие чужих регионов, запрет списка пользователей, выход и 401, ошибочный пароль, повторный вход, конфликт повторной регистрации — успешно (`scripts/smoke_auth.py`).
- Chromium: регистрация через форму, профиль, сохранение сессии после reload, отказ доступа к разделу чужой роли, выход, сообщение при неверном пароле, повторный вход — успешно. Ширина 390 px — без горизонтального переполнения и runtime-ошибок.
- OpenAPI возвращает 10 действующих путей; Redis отвечает `PONG` (прикладное кэширование пока не реализовано).
- Реальный вход в Google **не проверен**: OAuth client credentials не предоставлены. Проверены настройки callback/state и правила создания/поиска аккаунта на тестовых OIDC-данных.

Администрирование проверено 20.11.2026.

- Backend собран командой `mvn package` с `MYSQL_INTEGRATION_TESTS=true`. Все 26 тестов прошли. Миграция V4 сохранила учётную запись и назначение из базы V3.
- Frontend собран командой `npm run build`. Все 9 тестов прошли. В Chromium проверены создание пользователя, фильтры, ошибки формы, изменение данных, роли и пароля, блокировка, активация и управление назначениями. Форма помещается на экране шириной 390 px.
- HTTP-проверки подтвердили отзыв сессий, региональные ограничения, обработку конкурентных запросов и вход после смены логина администратора и перезапуска.
